Install it like a native app

TV Tracker is a Progressive Web App — add it to your home screen or dock for a full-screen, offline-ready experience with faster launches.

🖥️ Desktop — Chrome / Edge

  1. Open TV Tracker.
  2. Click the install icon in the address bar, or the ⋮ menu → Install TV Tracker.
  3. Launch it anytime from your dock, taskbar, or Start menu.

📱 iPhone / iPad — Safari

  1. Open TV Tracker in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then Add.

🤖 Android — Chrome

  1. Open TV Tracker in Chrome.
  2. Tap the ⋮ menu.
  3. Choose Install app (or Add to Home screen).

Your data stays yours

Everything you track is stored locally in your browser — there are no accounts and no server database. Google Drive sync is optional and uses a private, app-only folder. Read the privacy policy.
